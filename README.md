# TV Music

Ứng dụng nghe nhạc dành cho **Android TV & Android**, hỗ trợ duyệt thư mục trên máy / thẻ nhớ / USB, phát nhiều định dạng âm thanh và tùy biến giao diện **Apple TV (Hiệu ứng kính)** cùng ảnh nền qua mã QR.

## Tính năng nổi bật
- **Đa định dạng âm thanh**: `FLAC`, `WAV`, `MP3`, `AAC / M4A`, `OGG`, `OPUS`.
- **Duyệt thư mục trực tiếp**: Quét bộ nhớ thiết bị hoặc chọn thư mục tùy chỉnh từ USB / thẻ nhớ.
- **Hai phong cách giao diện**: **Nền Trắng Thanh Lịch** và **Apple TV (Hiệu ứng kính mờ tvOS)** với tùy chỉnh độ mờ kính.
- **Đổi ảnh nền qua mã QR**: Quét QR từ điện thoại (cùng Wi-Fi) hoặc chọn ảnh có sẵn, tùy chỉnh độ trong suốt `0% – 100%`.
- **Điều khiển linh hoạt**: Tối ưu cho cả **Remote TV (D-Pad)** và **Chuột / Air Mouse** (hover, click, cuộn).

## Tải file APK
Tải bản cài đặt `.apk` mới nhất trực tiếp tại mục **Releases** ở trang chủ repository (bên phải trang GitHub).

## Tự build APK
```bash
./gradlew assembleDebug
```
File APK xuất ra tại `app/build/outputs/apk/debug/app-debug.apk`.
